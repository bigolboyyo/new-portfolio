# Wesley Grant

A personal landing page built with Next.js and Tailwind CSS.

## Features

- Responsive personal introduction
- Rotating profile imagery
- Contact links with a copy-email button

## Run locally

1. Install Node.js 18+ or your preferred LTS version.
2. In the project root, run:
   npm install
   npm run dev
3. Open http://localhost:3000

## Production build

npm run build
